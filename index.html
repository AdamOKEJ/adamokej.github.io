Instalacja XAMPP

Pierwsze uruchomienie wymaga jednorazowego importu konfiguracji bazy.

Pobierz konfiguracja.sqlPobierz XAMPP
  1. Zainstaluj XAMPP dla Windows z Apache, MariaDB, PHP i phpMyAdmin.
  2. Rozpakuj ZIP. Skopiuj tylko katalog inf03-lab-public do C:\xampp\htdocs lub do katalogu htdocs w swojej instalacji. SQL i dokumenty trzymaj poza htdocs.
  3. W panelu XAMPP uruchom Apache oraz MySQL.
  4. Otwórz phpMyAdmin. Jako administrator lokalnej bazy wybierz Import, wskaż konfiguracja.sql i wykonaj import. Skrypt ustawia konta i uprawnienia dla schematów treningowych.
  5. Otwórz 127.0.0.1/inf03-lab-public/, przeczytaj ostrzeżenie i rozpocznij naukę.

Apache wymaga obsługi .htaccess i mod_rewrite. PHP wymaga CLI, mysqli oraz proc_open. Przy niestandardowym porcie Apache dopisz go do adresów, a port MySQL ustaw w inf03-lab-public/config.php.

Instalacja Public EXE

Windows x64 i zgodny XAMPP. Electron 45.5.0 jest już w instalatorze.

Pobierz XAMPP
  1. Zainstaluj XAMPP z PHP CLI (mysqli i proc_open) oraz narzędziami MariaDB do tworzenia, uruchamiania i obsługi bazy.
  2. Uruchom instalator Public EXE jako zwykły użytkownik i wybierz folder instalacji.
  3. Otwórz skrót INF03 Lab Public Beta. Przy pierwszym starcie przeczytaj ostrzeżenie. Jeśli XAMPP jest w nietypowej lokalizacji, wpisz pełną ścieżkę w xampp-path.txt w folderze programu.

Launcher sam uruchamia lokalne PHP i tymczasową instancję MariaDB. Nie musisz startować Apache ani MySQL w panelu XAMPP ani importować pliku SQL. W razie błędu sprawdź %LOCALAPPDATA%\INF03Lab-Public\logs.

EXE jest bardziej eksperymentalne niż wersja XAMPP.* Sprawdzono instalację, reinstalację i odinstalowanie. Pełna sesja kursu w oknie Electron z MariaDB pozostaje do sprawdzenia. Instalator i launcher są niepodpisane. Lokalny skan Defendera nie wykrył zagrożeń w aktualnych plikach, ale wcześniejsze wykrycie pozostało niewyjaśnione. Nie wyłączaj ochrony antywirusowej.

* Na niektórych komputerach EXE może w ogóle się nie uruchomić. W skrajnym przypadku pozostaje je odinstalować. Jeśli antywirus zgłosi zagrożenie lub zablokuje plik, zostaw ochronę włączoną, usuń instalator i wypróbuj wersję XAMPP.

W zakresie dopuszczalnym przez prawo wydawca nie ponosi odpowiedzialności za szkody wynikające z instalacji lub użytkowania, w tym za awarie i utratę danych. Nie ogranicza to praw użytkownika wynikających z obowiązujących przepisów.

Aplikacja wykonuje rzeczywisty kod PHP, JavaScript i SQL. Izolacja nie jest pełna. Używaj własnego, zaufanego kodu i danych treningowych. Nie wystawiaj backendu do internetu ani sieci lokalnej. Przed testami wykonaj kopię ważnych danych. Zalecana jest odizolowana maszyna wirtualna.

Kod i materiały są przeznaczone do bezpłatnej nauki. Komponenty zewnętrzne mają odrębne licencje. Szczegóły zawiera LICENCJE.txt w każdym wydaniu. Publikacja plików nie nadaje całemu projektowi licencji open source.

Prywatność i dane

Kurs działa bez kont, reklam i wbudowanej telemetrii. Dane zapisane przez kurs nie mają dodatkowego szyfrowania. Strona nie używa własnych plików cookie, analityki, reklam ani formularzy zbierających dane. Hosting zapewnia GitHub Pages. GitHub może przetwarzać dane techniczne, w tym adres IP odwiedzającego.

Polityka prywatności GitHuba

XAMPP. Postępy i historia są w pamięci przeglądarki. Apache może zapisywać logi zależnie od konfiguracji XAMPP. Pliki robocze trafiają poza htdocs, a bazy treningowe są resetowane. Awaria może pozostawić pliki lub schematy.

EXE. Kod, wyniki, ustawienia i historia są w %LOCALAPPDATA%\INF03Lab-Public\profile. Logi trafiają do podfolderu logs obok profilu. Tymczasowa baza i podglądy są zwykle usuwane przy prawidłowym zamknięciu. Odinstalowanie zachowuje profil. Historię można wyeksportować z aplikacji.

Ręczne usuwanie danych EXE. Zamknij INF03 Lab Public Beta. W Eksploratorze plików wpisz %LOCALAPPDATA% w pasku adresu i usuń folder INF03Lab-Public. Usunie to lokalny kod, postępy, historię, ustawienia i logi tej wersji. Jeśli chcesz zachować historię, wyeksportuj ją przed usunięciem folderu.
